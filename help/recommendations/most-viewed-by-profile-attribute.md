# Más visitados por recomendaciones basadas en atributos de perfil

En este vídeo se explica cómo utilizar la función Más visitados por atributos de perfil de Adobe Target para ofrecer recomendaciones localizadas específicas de segmentos, en lugar de una lista de popularidad única para todos. Al configurar un script de perfil simple y seleccionar el algoritmo de popularidad de atributo de perfil, las empresas pueden adaptar dinámicamente el contenido &quot;más visto&quot; en función de atributos como el país del usuario, el nivel de suscripción o la población.
